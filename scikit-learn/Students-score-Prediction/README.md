# 🎓 Student Score Prediction using Linear Regression

A beginner-friendly Machine Learning project built with **Python** and **Scikit-learn** to predict student exam scores based on study hours using the **Linear Regression** algorithm.

---

## 📌 Project Overview

This project demonstrates the complete Machine Learning workflow:

- Data Loading
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature & Target Selection
- Train-Test Split
- Model Training
- Prediction
- Model Evaluation
- New Data Prediction

---

## 📂 Dataset

**Input Feature**
- Hours Studied

**Target**
- Student Score

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📊 Machine Learning Workflow

1. Import Libraries
2. Load Dataset
3. Perform Basic EDA
4. Visualize Data using Scatter Plot
5. Select Features (X) and Target (y)
6. Split Data into Training & Testing Sets
7. Train Linear Regression Model
8. Make Predictions
9. Evaluate Model
10. Predict Score for New Data
