# Salary Prediction using Machine Learning

A Machine Learning regression project that predicts employee salary using demographic, education, and professional experience features.

## Features

- Age
- Gender
- Education Level
- Years of Experience
- Salary (Target)

## Machine Learning Workflow

Data Cleaning → EDA → Encoding → Train-Test Split → Feature Scaling → Linear Regression → Prediction → Evaluation

## Model

**Multiple Linear Regression**

## Model Performance

- MAE: 9,900.27
- MSE: 176,345,374.06
- RMSE: 13,279.51
- R² Score: 0.9088

The model achieved an R² score of **90.88%** on the test dataset.
