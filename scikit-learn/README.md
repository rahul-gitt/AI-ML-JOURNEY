# Scikit-Learn

A comprehensive repository documenting my journey of learning **Scikit-Learn**, one of the most popular machine learning libraries in Python.

## 📚 About

This repository contains well-structured notes, hands-on practice, and machine learning implementations using Scikit-Learn. It covers the complete workflow, from data preprocessing to model building, evaluation, and optimization.

## 🚀 Topics Covered

* Introduction to Scikit-Learn
* Machine Learning Workflow
* Built-in Datasets
* Data Preprocessing
* Train-Test Split
* Feature Scaling
* Label Encoding
* One-Hot Encoding
* Linear Regression
* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Trees
* Random Forest
* Support Vector Machine (SVM)
* Naive Bayes
* Model Evaluation
* Cross Validation
* Hyperparameter Tuning
* Pipelines
* Model Persistence (Joblib & Pickle)
* End-to-End Machine Learning Projects

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-Learn
* Jupyter Notebook
* VS Code

## 🎯 Goal

The goal of this repository is to build a strong foundation in machine learning using Scikit-Learn through practical examples, clean code, and real-world projects.
